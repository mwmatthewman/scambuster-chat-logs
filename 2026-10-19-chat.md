## Use all the info saved at my github to give me a brief summary of what the scambuster app is supposed to do

**ScamBuster** stalls telemarketers so you never have to stay on the line or agree to buy. The home line is “Keep them talking. Never say yes.”

The goal is: an unknown number rings, you don’t pick up, and the call goes to a second number the app controls. That line answers, listens to what the caller actually says, and talks back. It does not follow a canned script (warranty, solar, debt, and so on). It never agrees to a purchase and never gives a card or identity number. Your phone stays free for other calls and browsing, and it does not use the speaker.

What is built today is a pinned website, not a dialer. It cannot answer a ringing Android call. It opens the Phone app and dials a carrier forward code (T-Mobile, AT&T, or Verizon) to a number you type. The practice screen rehearses the stall with moods and a shareable recording; that is not the live call.

## The app should be able to be installed on all us mobile phones, android, apple, goigle etc. When a call is ringing, the user will be given an additional prompt that will send that particular call to scambuster. Not any unanswered call, only the ones the user actively sends. The caller will then be connected to an ai agent designed to waste the salespersons time without ever agreeing to a purchase or providing any information. The user should have the abillity to record thier own voice so it can be cloned by the AI agent, and the user should be able to download the audio of the conversation. What is necessary to make this app a reality, and what infrastructure would be needed

A normal app cannot add a button to the iPhone or Android Phone screen and move that one cellular call. ScamBuster has to be the line the call is ringing on. The button then sits on ScamBuster’s own incoming-call screen, and only a tap sends that call to the agent.

US carriers can forward every call, or every unanswered call. They do not offer “send this one ringing call.” iOS draws an incoming-call screen only for calls your own service receives. Android still will not give an app the audio of a carrier call, so the phone cannot secretly bridge Verizon or AT&T audio to your AI. Google phones are Android phones. Feature phones cannot run this.

## Viable product

The user keeps a normal phone number, but that number lives on ScamBuster’s voice network, not on the carrier SIM. Calls ring in the ScamBuster app on iPhone and Android, including on the lock screen.

1. The phone rings. The screen shows who is calling, plus Answer, Decline, and Send to ScamBuster.
2. Answer and Decline behave like a normal phone. Nothing is sent to the agent.
3. Send to ScamBuster answers that call on your servers. The handset stays free for other calls and for browsing.
4. The agent hears the caller and talks back in the user’s cloned voice. It never agrees to buy and never gives a name, address, card, account, or identity number.
5. When the call ends, the user can download the audio.

What has to exist:

| Piece | What it is |
|---|---|
| iOS app | CallKit and PushKit so a call your service receives rings like a real call. Not a website. |
| Android app | A calling app using the Telecom APIs, same behavior. |
| Voice network | US phone numbers, number porting, SIP or WebRTC media, the ability to ring the app or bridge the caller to the agent. Twilio, Telnyx, or Bandwidth are the usual starting point. |
| Call control | Ring the handset first. Answer on the server only after that call’s button. If the user does nothing, the call is not sent. |
| Agent | Streaming speech-to-text, a model with hard rules, streaming text-to-speech, barge-in, hang-up detection. |
| Voice clone | In-app recording, explicit consent, a cloned voice stored per user and used only on calls they send. |
| Recordings | Encrypted audio storage and a signed-in download. |
| Accounts and billing | Sign-in, per-minute cost caps, a maximum call length. A long stall costs real money, roughly on the order of $0.05–$0.20 a minute once telephony, transcription, the model, and the cloned voice are added up. |
| Carrier duties | If this replaces their phone: 911, STIR/SHAKEN, porting authorization, and robocall registration. That is the expensive part of being real. |
| Legal | Always announce that the call is recorded before the conversation. All-party-consent states require it. The user must consent to the clone of their own voice. Do not use the clone to call anyone, or to sound like the user to a bank. |

The first version of the real product can be the app plus one ported number, with outbound calling limited to 911 and the user’s own test calls. You do not need every US carrier integrated. You need one voice provider that will port a US mobile number.

## Minimum demonstrator

This can be shown on a laptop or a phone without porting a number and without claiming a carrier call was intercepted.

- A real US number. Someone calls it from another phone. The agent answers, wastes time inside the rules, and the audio can be downloaded.
- A screen that looks like an incoming call, with the third button. Label it as the control the real app will have. Tapping it is what connects that test call to the agent.
- A short voice enrollment. The user records a few sentences, the next test call uses that clone, and a bad or short sample is rejected.
- A download button for that call’s audio file.

The demonstrator proves the agent, the clone, the recording, and the button. It does not prove a Verizon or AT&T ring was taken over. That claim has to wait until a number is actually ringing inside the app.

## Testing protocol

Run these in order. A later test does not count if an earlier one failed.

**1. Only the tapped call is sent.** Place three calls to the ScamBuster number. Decline the first. Answer the second and hang up. Send the third. Only the third may reach the agent. The first two must leave no agent recording.

**2. The handset is free.** After Send, place a second call from the phone and load a page. Both must work while the agent is still talking.

**3. The agent stays inside the rules.** Have a tester read a salesperson script: ask for the sale, a card number, a Social Security number, an address, a date of birth, and a “yes.” The agent must refuse all of them, must not invent personal details, and must not say it will buy. Repeat at least 20 times. One agreement or one piece of personal information is a fail.

**4. Voice clone.** Enroll with the required samples, then with a sample that is too short. The short sample must be rejected. On a sent call, a listener who knows the user should recognize the voice. The clone must not be offered for any outbound call.

**5. Recording.** The caller must hear the recording notice before any pitch. The downloaded file must contain both sides, from the notice through hang-up, and must not be downloadable by another account.

**6. Phones.** Repeat tests 1, 2, and 5 on one current iPhone and one current Android phone, with the screen locked when the call arrives. A website added to the home screen does not count as a pass.

**7. Stop conditions.** The agent hangs up at the time limit. A dropped network connection ends the call and still saves whatever audio was captured. The user can stop an active agent call from the app.

**8. Do not test on a live salesperson until 1 through 7 pass.** The first live test is one opted-in caller on a number you control, not a real telemarketer.

## Can an app create a button on the incoming call screen that would forward that call to scambusters servers

No. An app cannot put a button on the carrier incoming-call screen and send that cellular call to ScamBuster’s servers.

On an iPhone, a third-party app cannot change the Phone screen for a normal Verizon, AT&T, or T-Mobile call. Apple’s call screen is available only for a call your own service is already receiving. There is no button you can add that forwards the carrier call.

On Android, replacing the Phone app lets you draw an extra button on the incoming-call screen. Pressing it still cannot move that call. Android does not give an app the audio of a carrier call, and its redirect API applies to calls the user is dialing, not calls that are ringing. US carriers also have no “send this one ringing call” feature an app can trigger.

The button works only when the call is already ringing inside ScamBuster, because the number is on ScamBuster’s voice network. Answer and Decline stay on the phone. Send to ScamBuster tells your server to pick up that call.
